# ボディコンバット プログラム作成

30分・45分・60分の決まった曲順、またはカスタムで決めた曲順に合わせて、過去の BodyCombat リリースから時間内に収まるクラスを作ります。

## 起動

```bash
npm install
npm run bodycombat
```

ブラウザで http://localhost:1237/bodycombat.html を開きます。

## 曲データ

初期データは [ボディコンバットナビの曲紹介](https://www.fhstr.net/archives/34) と、そこから辿れる各 BC リリースの掲載（曲名・アーティスト・トラック番号）です。アプリ内の `src/bodycombat/catalog.js` に保存してあり、再生時に外部へ曲一覧を送りません。

このサイトに曲一覧がない BC2 と BC3 は入っていません。掲載が曲ごとに分かれているリリースは、個別記事とシリーズの曲リストの両方から補っています。

評価（1〜5）は仮の値です。長さもクラスが指定時間に収まるように置いた目安で、公式の収録時間ではありません。どちらも画面上で変更でき、このブラウザの localStorage（`bodycombat:meta:v1`）に残ります。

## クラスの構成

- **60分（マスタークラス）**: トラック1A、1B、2、3、4、5、6、7、8、9、10を順番どおり。トラック5が5A/5Bに分かれている曲は、その2曲をパワー2として続けます。
- **45分**: トラック1〜7を連続し、最後の1曲だけトラック8（パワー3）、9（筋力コンディショニング）、10（クールダウン）のどれかにします。
- **30分（ショート）**: ウォーミングアップ（1A/1B、または分割されていないトラック1）、コンバット1、パワー1、ムエタイ、最後にトラック9または10。5〜6曲です。
- **カスタム**: 30・45・60分の右に1つだけあります。時間（30分・45分・60分のいずれか）、曲の種類、曲数、順番をこのブラウザに保存します。リリースによってトラックの分かれ方が違うときは、ここをそのリリースの並びに合わせます。

「猶予」は、開始の遅れ、途中の休憩、予定より早い終了に使う分数です。初期値は5分です。60分クラスなら曲の順番はそのまま、曲の合計だけ55分までにします。0〜15分に変えられ、変えた値はこのブラウザに残ります。

「別の組み合わせを作る」は評価が高い曲を優先しつつ、合計が曲の上限を超えない組み合わせを選び直します。曲の「固定」にチェックを入れると、その枠は再作成後も残ります。
